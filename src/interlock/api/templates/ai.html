Guardrails, enforced in code

  • The AI never records an outcome or files a case. A named person does both.
  • Every extracted value must quote the message verbatim, or it is dropped.
  • Bank identities are never taken from message text.
  • A suggestion must be legal for the case, cite only facts it was given, and cannot propose giving up before the deadline.
  • A drafted reply must state the recorded outcome, case id and exact amount, and may contain no number that is not in the case.
  • If a check fails or the model is down, the screen says so. It never shows a default in its place.
